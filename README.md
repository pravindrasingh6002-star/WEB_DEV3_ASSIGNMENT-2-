# WEB DEV 3 - Assignment 2

## Student REST API

This project is a simple REST API developed using **Node.js and Express.js** as part of Web Development 3 Assignment 2.

The API provides basic CRUD operations for managing student records.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- Postman
- Git & GitHub

## Project Features

- Get all students
- Get a student by ID
- Add a new student
- Update student information
- Delete a student
- JSON-based API responses
- Custom middleware for logging

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/students` | Get all students |
| GET | `/students/:id` | Get student by ID |
| POST | `/students` | Add a new student |
| PUT | `/students/:id` | Update student details |
| DELETE | `/students/:id` | Delete a student |
